# User Guide

ဤ User Guide တွင် FMS ကို နေ့စဉ်အသုံးပြုရာ၌ လိုအပ်သော လုပ်ဆောင်ချက်များကို အပိုင်းလိုက် စုစည်းဖော်ပြထားပါသည်။ ဘယ်ဘက်ရှိ MkDocs Menu မှ သက်ဆိုင်ရာအပိုင်းကို ရွေးချယ်၍ ဖတ်ရှုနိုင်ပါသည်။

## User Guide Sections

- [Application Website](application-website.md) — Login, Dashboard နှင့် ဆီဆိုင်နေ့စဉ်လုပ်ငန်းစဉ်များ
- [Device Control](device-control.md) — Nozzle, Preset နှင့် Permit လုပ်ဆောင်ချက်များ
- [Sales Management](sales.md) — Daily Sale, User Roles နှင့် Credit Sale
- [Reports & Tank Management](reports.md) — Tank Data နှင့် Report များ
- [Master Data Management](master-data.md) — Companies နှင့် Customers
