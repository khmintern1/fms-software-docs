# 1. Before You Begin

Station Setup မစတင်မီ ဆိုင်ဘက်မှ အောက်ပါအချက်အလက်များကို ကြိုတင်မေးမြန်းပြီး မှတ်တမ်းတင်ထားပါ။

## 1.1 Tank နှင့် Nozzle ဆိုင်ရာ အချက်အလက်များ

- မည်သည့် Nozzle ကို မည်သည့် Tank နှင့် ချိတ်ဆက်ထားသည်ကို အတည်ပြုပါ။
- ဆိုင်ရှိ Tank အရေအတွက်နှင့် Nozzle အရေအတွက်ကို သိရှိထားပါ။
- Tank တစ်ကန်ချင်းစီ၏ ရောင်းချသည့် Fuel Type နှင့် Sale Price ကို မေးမြန်းထားပါ။
- Tank တစ်ကန်ချင်းစီ၏ လက်ရှိကျန်ရှိသော ဆီပမာဏကို တိုင်းတာထားပါ။
- နောက်ဆုံး Fuel In ဝင်ထားသည့် အချက်အလက်များကို ရယူထားပါ။

## 1.2 ATG ဆိုင်ရာ အချက်အလက်များ

ATG တပ်ဆင်ထားသောဆိုင်ဖြစ်ပါက Tank Setup ပြုလုပ်ရာတွင် အသုံးပြုရန် ATG စက်ရှိ Tank Information များကို ကြိုတင်မှတ်တမ်းတင်ထားပါ။

## 1.3 History အတွက် ကြိုတင်စုဆောင်းရန်

Tank တစ်ကန်ချင်းစီအတွက် အောက်ပါ History အချက်အလက်များကို မေးမြန်းထားပါ။

| Field | အဓိပ္ပာယ် |
|---|---|
| Sale Count | စုစုပေါင်း အရောင်းအကြိမ်ရေ |
| Sale Amount | စုစုပေါင်း အရောင်းပမာဏ |
| Sale Price | ရောင်းချသည့် ဆီဈေးနှုန်း |
| Sale Liter | စုစုပေါင်း အရောင်းလီတာ |
| Opening Balance | ဆီမရောင်းချမီ Tank အတွင်းရှိ ဆီလက်ကျန် |
| Closing Balance | ဆိုင်သိမ်းချိန် Tank အတွင်းရှိ ဆီလက်ကျန် |

> **Installer မှတ်ချက်:** History အချက်အလက်များသည် Setup ပြုလုပ်ချိန်တွင် ထည့်သွင်းရန် လိုအပ်သည်။ မူရင်းလမ်းညွှန်အရ Setup ပြီးနောက် History ထပ်မံထည့်ရန် မလိုတော့ပါ။
