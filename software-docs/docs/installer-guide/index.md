# Sixth Kendra – Software Setup Guide for Installers

ဤစာတမ်းသည် Sixth Kendra Fuel Management System (FMS) ကို ဆီဆိုင်အသစ်တစ်ဆိုင်တွင် စတင်အသုံးပြုနိုင်ရန် Installer မှ ဆောင်ရွက်ရမည့် Setup လုပ်ငန်းစဉ်များကို အဆင့်လိုက်ဖော်ပြထားသည်။

## လုပ်ငန်းစဉ်အကျဉ်း

1. Setup မစတင်မီ လိုအပ်သော ဆိုင်၊ Tank၊ Nozzle နှင့် History အချက်အလက်များကို စုဆောင်းပါ။
2. Installer Account ဖြင့် Login ဝင်ပြီး Shop နှင့် Station ကို ဖန်တီးပါ။
3. Tank၊ Fuel Type၊ History နှင့် Stock Price များကို သတ်မှတ်ပါ။
4. Dispenser နှင့် Nozzle များကို Setup ချပါ။
5. Cashier Account ဖန်တီးပြီး စမ်းသပ် Login ဝင်ပါ။
6. ATG ရှိ/မရှိအလိုက် Fuel In ကို စတင်မှတ်တမ်းတင်ပါ။
7. လိုအပ်ပါက Firmware OTA Update ကို ဆောင်ရွက်ပါ။
8. နောက်ဆုံး Installer Checklist ဖြင့် Setup ပြီးစီးမှုကို စစ်ဆေးပါ။

## အရေးကြီးသော သတိပြုရန်

- Tank နှင့် Nozzle ချိတ်ဆက်မှုကို မသေချာဘဲ Stock Price သို့မဟုတ် Nozzle Setup မလုပ်ပါနှင့်။
- Liter နှင့် Gallon ကို မှန်ကန်စွာ ပြောင်းလဲတွက်ချက်ပါ။
- Nozzle Number တစ်လုံးမှ ကိုးလုံးအထိကို `01`, `02` စသည့် Leading Zero ဖြင့် ထည့်ပါ။
- ATG မရှိသောဆိုင်နှင့် ATG ရှိသောဆိုင်၏ Fuel In လုပ်ငန်းစဉ် မတူညီပါ။
- ဤလမ်းညွှန်တွင် မူရင်း PDF မှ အချက်အလက်များကို စနစ်တကျ ပြန်လည်စီစဉ်ထားသည်။ မူရင်းတွင် မဖော်ပြထားသော Configuration များကို ကိုယ့်သဘောဖြင့် မဖြည့်ထားပါ။
