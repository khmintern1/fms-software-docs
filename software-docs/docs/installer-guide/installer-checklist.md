# 9. Installer Checklist – Do’s and Don’ts

Setup ပြီးဆုံးချိန်တွင် အောက်ပါအချက်များကို ဆိုင်တာဝန်ရှိသူနှင့် ပြန်လည်ရှင်းပြပြီး စစ်ဆေးပါ။

## 9.1 Do’s

- [ ] Navbar ပေါ်ရှိ `Start` နှင့် `End` Button များကို နေ့စဉ် အသုံးပြုရန် ဆိုင်ဝန်ထမ်းများအား သင်ပြပါ။
- [ ] ATG မရှိသောဆိုင်ဖြစ်ပါက `Sale Ledger` ရှိ `Add Today Tank Balance` တွင် နေ့စဉ် ဆိုင်သိမ်းချိန် Tank လက်ကျန်များ ထည့်ရန် ရှင်းပြပါ။
- [ ] Stock Price Setup ပြုလုပ်ရာတွင် Fuel Type နှင့် Tank ကိုက်ညီမှုကို စစ်ဆေးပါ။
- [ ] Software မှ Production Update ထုတ်ပြန်ပြီးပါက ဆိုင်များတွင် Version ကိုက်ညီစေရန် Update လုပ်ပေးပါ။

## 9.2 Don’ts

- [ ] Nozzle No. သည် 10 အောက်ဖြစ်ပါက ရှေ့ရှိ Zero ကို မဖြုတ်ပါနှင့်။ ဥပမာ `01` ဟု ထည့်ပါ။
- [ ] Car No. တစ်ခုတည်းကို Vehicle Type အမျိုးမျိုးအတွက် မသတ်မှတ်ရန် ဆိုင်အား ရှင်းပြပါ။
- [ ] Preset ပေးရာတွင် Liter နှင့် Kyat ကို မမှားစေရန် ဆိုင်ဝန်ထမ်းများအား သင်ပြပါ။ မူရင်းလမ်းညွှန်အရ မှားယွင်းပါက Cloud Report များတွင် Conflict ဖြစ်နိုင်သည်။

## 9.3 Handover Review

- [ ] Shop နှင့် Station မှန်ကန်စွာ ဖန်တီးထားသည်။
- [ ] Tank အရေအတွက်၊ Fuel Type နှင့် Capacity မှန်ကန်သည်။
- [ ] Tank လက်ကျန်နှင့် History အချက်အလက်များ အတည်ပြုပြီးဖြစ်သည်။
- [ ] Stock Price များကို Fuel Type အလိုက် ထည့်ပြီးဖြစ်သည်။
- [ ] Dispenser No. နှင့် Device IP များ မှန်ကန်သည်။
- [ ] Nozzle များကို သက်ဆိုင်ရာ Tank/Stock Price နှင့် ချိတ်ဆက်ထားသည်။
- [ ] Cashier Account ဖြင့် Login ဝင်နိုင်သည်။
- [ ] ATG ရှိ/မရှိအလိုက် Fuel In လုပ်ငန်းစဉ်ကို စမ်းသပ်ပြီးဖြစ်သည်။
- [ ] ဆိုင်ဝန်ထမ်းများအား နေ့စဉ် လိုက်နာရမည့်အချက်များ ရှင်းပြပြီးဖြစ်သည်။
